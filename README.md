# Hirelytics 📊👥
Hirelytics connects the two; tracking the hiring process and follows the hired employees' performance KPIs, allowing the company to see which hiring sources, stages and candidate profiles produce the best agents.

> This is our graduation project for Round 5 of Digital Egypt Pioneers Initiative (DEPI) organized by the Egypt's Ministry of Communications and Information Technology (MCIT), under the Professional Data Analysis Track 2026.
--- 

## Project Overview:
Call centers hire in high volume and lose many new hires early, yet hiring data and post-hire performance data usually sit in separate files. **Hirelytics** connects the two: it tracks every stage of the hiring process (applications to hire) and then follows the hired employees' performance KPIs, so the company can see which hiring sources, stages and candidate profiles produce the best agents.

## Project Objectives :
1. Build a clean, linked dataset from the two existing Excel sheets (hiring process and KPIs). 
2. Analyze the hiring funnel: volume, conversion between stages, time to hire, and dropoff points. 
3. Analyze hired-employee performance against the agreed KPIs and identify top and bottom performers and trends. 
4. Link both phases to answer: which hiring factors (source, assessment score, interviewer, training result) predict performance and retention. 
5. Deliver an interactive Power BI dashboard with hiring KPIs and performance KPIs with a final report.

## Gap and contribution :
1. Reviewed studies focus mainly on predicting turnover, not on following the whole funnel from application to KPI performance. 
2. Industry KPI guides cover performance KPIs but not how hiring decisions shape them. 
3. Hirelytics contributes one connected view: hiring funnel KPIs, employee performance KPIs, and the factors linking them, in a dashboard a recruiter or operations manager can use.
